# Личный кабинет — сервис сообщений

Учебный фронтенд-проект: HTML + CSS + немного JS. Данные не выдуманы —
всё, что видно на странице, либо реально отправлено через форму, либо
пара примеров входящих для наглядности. Хранение — в localStorage
браузера (без бэкенда), поэтому счётчики и лента ведут себя как в
рабочем приложении: пусто, пока ничего не произошло.

## Страницы

- **`index.html`** — «Сообщения»: форма отправки нового сообщения и лента.
  При первом заходе в ленте два примера входящих сообщений (для
  наглядности), исходящих — ноль, пока не отправите своё. Каждое
  отправленное сообщение сразу появляется в ленте и сохраняется.
- **`stats.html`** — «Статистика»: карточки «Всего / Отправлено /
  Получено» и таблица активности по дням — оба блока считаются от
  реальных сообщений из `index.html`. Если сообщений ещё нет — честно
  показывает 0 и пустое состояние, а не выдуманные цифры.

## Структура

```
personal-cabinet/
├── index.html        — страница сообщений
├── stats.html        — страница статистики
├── style.css         — все стили (обычный CSS)
├── js/
│   ├── storage.js     — общее хранилище сообщений (localStorage)
│   ├── messages.js    — рендер ленты + отправка формы
│   └── stats.js        — подсчёт статистики из тех же данных
└── README.md
```

## Как открыть

Просто откройте `index.html` в браузере — сборка не требуется. Данные
хранятся в localStorage конкретного браузера, так что «Статистика»
считает то, что вы реально отправили на странице «Сообщения».

## Дальнейшая интеграция в Yii2

- `style.css` подключить в `AssetBundle`.
- Разметку `.sidebar` / `.topbar` вынести в `layouts/main.php`.
- `storage.js` заменить на реальные запросы к контроллеру (AJAX/API),
  формат объекта `{ type, contact, text, time, date }` соответствует
  будущей модели `Message`.
- Карточки статистики и таблицу по дням заполнять данными из
  соответствующего контроллера вместо `stats.js`.
